# AdoptionTracer

Measures how long machine learning research takes to reach practice by
tracing backward from practitioner artifacts (open-source tools, benchmarks,
regulatory frameworks) to the arXiv papers they incorporate, and dating each
incorporation from the artifact's Git history.

This repository contains the tool, the frozen data, and the scripts that
reproduce every number and figure in

> Khanal, Basirat, Jasser, Garibay. *Measuring the Integration of Adversarial
> Machine Learning into Practice Through Artifact-Anchored Methodology.*
> ACML 2026, PMLR 353.

## Reproduce the paper

```bash
git clone https://github.com/actionproject-madhav/adoptiontracer
cd adoptiontracer
pip install -e ".[analysis]"

python analysis/reproduce.py > results.txt   # every statistic in the paper
python analysis/figures.py                   # figures/*.pdf (needs a LaTeX install)
```

`reproduce.py` reads only the frozen files in `data/` and prints each statistic
with the section of the paper it belongs to. It needs about ten seconds.
`figures.py` renders text with LaTeX so the figures match the paper body;
without a TeX installation, set `"text.usetex": False` in its `rcParams`.

## Use the tool

```bash
pip install -e .

adoptiontracer scan                          # the nine AML artifacts, results/
adoptiontracer scan -c my_artifacts.yaml -o out/
adoptiontracer events -o events/             # every first introduction, one CSV per artifact
adoptiontracer lookup --arxiv 1706.06083     # where and when one paper was integrated
```

`scan` clones each artifact repository, collects every arXiv identifier in the
tracked files at HEAD, resolves titles and dates from the arXiv API, dates the
earliest commit that introduced each identifier, and writes
`papers_all.csv`, `papers_selected.csv`, and `summary.json`.

To study another field, copy `adoptiontracer/artifacts.yaml` and edit the
`artifacts` list; the pipeline is otherwise unchanged.

### Dating method

An integration event for a (paper, file) pair is the earliest commit on any
branch whose added lines contain the paper's arXiv identifier
(`git log --all --reverse -p`, author date). Author dates survive rebases and
squashes that rewrite committer metadata. Live scans of actively developed
repositories will drift from the frozen data when upstream history is rewritten;
the paper's numbers come from `data/`, not from a fresh scan.

## Repository layout

```
adoptiontracer/     the package (clone, extract, resolve, trace, history, cli)
analysis/           reproduce.py, figures.py
data/               frozen inputs; see data/README.md for every file and column
figures/            the three figures of the paper as regenerated by figures.py
```

## Requirements

Python 3.10 or newer and Git. The tool itself depends only on PyYAML. The
analysis extra adds pandas, numpy, scipy, statsmodels, lifelines, and
matplotlib.
